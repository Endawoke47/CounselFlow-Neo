# Quick Start Commands

## 1. Install flyctl CLI
```powershell
irm https://fly.io/install.ps1 | iex
```

## 2. Login to Fly.io
```powershell
flyctl auth login
```

## 3. Deploy
```powershell
./deploy.ps1
```

## 4. Check Status
```powershell
flyctl open
```

That's it! Your app will be live at https://counselflow-ultimate.fly.dev
